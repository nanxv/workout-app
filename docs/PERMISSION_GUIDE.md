# 权限引导（显示给用户的文案）

## 健康（HealthKit）未授权
要让训练记录写入"健康"，请在 iPhone 前往：
设置 → 健康 → 数据访问与设备 → 选择本应用 →
允许【写入：锻炼；读取：锻炼/心率/活动能量/步行+跑步距离】。

## 日历（Calendar）未授权
若想把训练保存到日历，请前往：
设置 → 隐私与安全性 → 日历 → 允许本应用访问。

## Nike Run Club 跑步导入
要导入 NRC 的跑步数据，请在 iPhone 前往：
设置 → 健康 → 数据访问与设备 → Nike Run Club →
允许【写入：锻炼/心率/活动能量/步行+跑步距离】。
完成一次 NRC 跑步后，返回本应用的 Cardio 页面下拉刷新即可看到。
